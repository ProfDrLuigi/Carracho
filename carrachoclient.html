New in 1.0.4

  • Added native Classic user-icon support. Historical 636-byte Carracho avatars are now decoded with the original 16x16 QuickDraw palette layout and shown across Users, Conferences, Private Messages, News, and Transfers.
  • Classic avatars keep their original square presentation instead of being cropped by the modern circular avatar mask, while modern PNG avatars retain the existing rounded appearance.
  • Fixed a Classic download compatibility problem that could crash the original client. Legacy downloads now negotiate both data-fork and resource-fork resume offsets and lengths exactly as expected by the historical protocol.
  • Expanded Conference moderation controls so room operators can grant or remove Operator Mode and Speak Permission directly from the participant list and member controls.
  • Administrators connected to a modern Carracho Server can now permanently delete non-Public Conferences from the room list or the active room.
  • Refreshed the application theme with quieter full-row selections, dedicated side-column backgrounds, improved dark-mode colors, and more consistent Chat, Files, News, Transfers, and administration surfaces.
  • Redesigned Conference transcripts with user avatars, clearer author/timestamp presentation, improved spacing, and better preservation of text selection while live updates arrive.
  • Improved News scrolling so live refreshes preserve the current reading position instead of fighting trackpad or mouse-wheel movement.
  • Improved Files presentation with denser rows, scalable icons, and visual styling consistent with the rest of the refreshed interface.
  • Improved client metadata and Classic/modern interoperability, including more accurate runtime architecture reporting and more reliable Legacy user-picture synchronization.

New in 1.0.3

  • Greatly improved scrolling performance in large Files listings by avoiding repeated full-directory sorting during table rendering and by caching file icons and formatters.
  • Classic text emoticons such as :D, :-), ;), :P, :O, :/, :'(, and <3 are now displayed as modern emoji in Chat, Private Messages, Offline Messages, and Broadcasts while the original wire text remains unchanged for Legacy compatibility.
  • Improved modern-to-Classic text compatibility: when talking to an older server, modern emoji can be represented by compact readable aliases such as *laughing* instead of being silently lost.
  • Improved image pasting in Chat and News so artwork copied from more macOS applications and clipboard formats, including PDF-, JPEG-, HEIC-, PNG-, and TIFF-backed images, can be attached normally.
  • Pasting a supported YouTube URL into Conference Chat, News, or a News reply can now add it directly as a YouTube attachment.
  • Improved rich-content hover presentation with a dedicated inline popover instead of relying on the standard AppKit tooltip behavior.
  • Account administration now shows per-account download and upload counts as well as transferred data totals, with sortable columns for both local and remote administration.
  • Improved account-group administration: accounts that still inherit their group's permissions and nickname color now follow later group-default changes, while explicit per-account overrides remain untouched.
  • Simplified dedicated group Files roots so the visible root name is derived from the final folder component instead of requiring a separate root-name field.
  • News reaction changes from other users now update live without requiring a manual News refresh.
  • Improved user-list synchronization for avatars, status messages, group colors, and Legacy-client markers, and changed the default ordering so longer-connected users remain near the top.
  • Improved connection-loss handling and localization for interrupted transfers, Tracker administration, file-root errors, Conference events, and other client status messages.
  • Server-wide file search results now show the clean file or folder name instead of the complete server path, and the Transfer Monitor follows the same filename-only presentation.
  • Improved the Overview Files panel so the first root item remains visible when long directory listings require a vertical scrollbar.
  • Improved Files navigation and refresh behavior so root and directory changes reliably return to the intended top position instead of inheriting stale scroll offsets.

New in 1.0.2

  • Added full Bot command-rule administration with per-rule enable/disable controls, editable commands and responses, and support for the {name} and {login} response placeholders.
  • Bot commands in Conferences now use the compact #<command> syntax, while direct private messages to the Bot can still use the command without a prefix.
  • Added Bot RSS/Atom feed administration with multiple configurable feeds, per-feed enable/disable state, target Conference, polling interval, optional images, summary length, feed name, and editable RSS URL.
  • Added convenient MacRumors and Tarnkappe feed presets. Additional RSS/Atom feeds can be added and configured manually.
  • The RSS Feed Test action now posts the fetched test article as a real Bot message in the Public Conference instead of showing it in a dialog.
  • Redesigned Conference posts with alternating full-width backgrounds, clearer separators, and timestamps placed before the nickname in each post header.
  • Improved the Conference participant list so long nicknames have more usable space and Operator, Speaker, or Member roles are shown at the upper-right of each participant row.
  • Private Message transcript cards are now consistently aligned to the left for both outgoing and incoming messages.
  • Improved the Bot administration layout and made RSS text fields such as Name, Minutes, Summary, and RSS URL directly editable in the table.
  • Expanded English and German localization for the new Bot command and RSS administration features.

New in 1.0.1

  • Added inline YouTube previews and playback in Chat and News, with a separate link to open videos on the YouTube website.
  • Improved bookmark connections, including correct server uptime display immediately after connecting and more reliable restoration of per-server UI state.
  • Added a first-run default bookmark for carracho.istation.pw using the anonymous account, while preserving an intentionally empty bookmark list after deletion.
  • Improved Files with immediate rename updates, live file-label synchronization, and automatic refresh when file or Dropbox permissions change for an already connected account.
  • Fixed file-list scroll restoration issues that could hide the first row when starting the client, switching between Overview and Files, or changing connected bookmarks.
  • Improved modern News posting with the new Post News permission and reliable server acknowledgements, so failed posts keep their draft instead of appearing to succeed.
  • Improved the Chat composer so it reliably accepts clicks after launch and workspace changes, and updated the text cursor to follow the system appearance.
  • Standardized primary action buttons to macOS system blue with white labels and icons.
  • Settings now opens on the General tab by default.
  • Expanded and corrected English and German localization throughout the client.
  • Closing the last Carracho window now cleanly quits the client and disconnects all active bookmark sessions.
