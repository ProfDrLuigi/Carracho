Carracho Server

Download Server releases separately from the macOS Client. The Server application and background service share a version number, but their source code still lives in the main Carracho project.

Separate repositories

Carracho-Server holds the Server release ZIP files and Server-only changelog. The Carracho source repository contains the shared Xcode project, Server source code and Client downloads.

Automatic updates

Already installed Carracho Servers continue to use the existing Sparkle update feed. New Server ZIPs are published in the separate Carracho-Server repository while this feed address stays in place. Historical signed archive URLs are preserved.

Before updating, back up the Server database. After updating the macOS Server application, also update the installed daemon using System Service → Update Now.
